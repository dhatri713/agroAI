# AgriAI - Pest & Disease Question Answering System

This project is an AI-powered system to help farmers get answers about crop diseases & pests. It uses vector search, LLMs, and a custom data pipeline.

## Tech Stack

| Part            | Library               | Purpose                             |
|-----------------|-----------------------|-------------------------------------|
| Embeddings      | sentence-transformers | Convert text to vectors             |
| Vector Storage  | ChromaDB              | Store & search embeddings           |
| LLM             | Groq API              | Query expansion & Answer generation |
| Language        | Python                | Everything else                     |

Will add TTS and STT layers soon to make it more accessible to Telugu farmers
